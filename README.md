# Slate

This is the public repository for Slate's open-source developer and agent ecosystem:

- consumer and management SDKs;
- CLI and MCP server;
- Codex and Claude Code plugins and skills;
- framework integrations and examples; and
- generated public bindings and safe conformance fixtures.

Slate is record-based content infrastructure. These clients use Slate's canonical hosted domain
operations; they do not implement a second authorization, workflow, publication or recovery model.

## Status

Initial repository setup is in progress. Package source, support claims and a license will be added
before the first public release.

See [`AGENTS.md`](AGENTS.md) before contributing.
